プライバシーポリシー

本ポリシーは、個人が開発・提供するウェブアプリ「家計簿的」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

1. 本アプリの概要

本アプリは、利用者自身の Google スプレッドシートに家計簿の記録を追加するためのツールです。 本アプリは独自のサーバーやデータベースを持たず、利用者のブラウザから Google の API を直接呼び出して動作します。

2. 取得する情報と利用目的

  • Google アカウントによる認証情報
    Google の OAuth 2.0 を用いて、利用者の Google アカウントでログインします。 本アプリが要求する権限（スコープ）は「このアプリで使用する特定の Google ドライブ ファイルの表示、編集、作成、削除」（drive.file）のみです。 これにより本アプリは、利用者が Google Picker で選択したスプレッドシートにのみアクセスでき、それ以外のファイルにはアクセスできません。
  • スプレッドシートの内容
    利用者が選択したスプレッドシートから、お財布および費目の選択肢（「設定」シート）を読み取ります。 また、利用者が入力した日付・お財布・費目・支出額・備考を、同じスプレッドシートに行として追加します。 これらの情報は利用者自身のスプレッドシートにのみ保存されます。
  • ブラウザに保存する情報
    利用者が選択したスプレッドシートの ID と名前を、利用者のブラウザの localStorage に保存します。 これは次回以降に同じスプレッドシートを自動的に使うためのもので、本アプリの開発者を含む第三者に送信されることはありません。

3. 情報の送信先と第三者提供

本アプリが取得した情報は、Google の API（Google Sheets API、Google Picker API、Google Identity Services）との通信にのみ利用されます。 本アプリの開発者が利用者の情報を収集・保存・閲覧することはなく、第三者への提供・販売も行いません。

4. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から取得した情報の利用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。

Kakeiboteki's (家計簿的) use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. アクセス権の取り消しとデータの削除

  • 本アプリへのアクセス権は、Google アカウントの 「サードパーティ製のアプリとサービス」からいつでも取り消すことができます。
  • ブラウザに保存された情報は、ブラウザのサイトデータを削除することで消去できます。
  • スプレッドシートに記録された内容は利用者自身の Google ドライブ上にあり、利用者が自由に編集・削除できます。

6. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更後の内容は本ページに掲載した時点で効力を生じます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub の Issue からお願いします。
