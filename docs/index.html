家計簿的

Google スプレッドシートに家計簿を素早く記録するための個人用ウェブアプリです。

できること

  • お財布・日付・費目・支出額・備考を入力し、ボタンひとつで家計簿のスプレッドシートに1行追加します。
  • お財布と費目の選択肢は、スプレッドシートの「設定」シートから読み込みます。
  • サーバーを持たず、ブラウザから Google の API を直接呼び出して動作します。

データの扱い

このアプリは、Google Picker であなたが選んだスプレッドシートにだけアクセスします。 入力した内容はあなた自身の Google スプレッドシートに直接保存され、アプリの開発者を含む第三者には送信されません。 詳しくは プライバシーポリシー をご覧ください。
